# 周报素材用户手册

> 适用对象：本容器（YatTerra Pod）内的用户与 agent。
> 用途：说明如何手动提交周报素材、素材如何被汇总、周报如何生成与发布。
> 更新时间：2026-10-14（北京时间）

## 1. 一句话概览

平时用 `note` 一句话记录改动 → 素材落进 `~/docs/notes/notes.jsonl` →
需要写周报时对 Claude 说「写周报」，素材自动汇总并发布到 iwiki「周报」空间。

## 2. 手动提交素材：`note` 命令

`note` 已在 PATH 中，任何终端直接可用（也可在 Claude 对话里输入 `! note "..."`）。

```bash
note "完成 RAG 网关超时重试逻辑，压测 TTFT 下降 40%"     # 记在今天（北京时间）
note "修复引擎 KV cache 泄漏" 2026-10-12                 # 补记到指定日期
note --agent "一句话总结" [日期]                          # agent 改动记录（一般由 Claude 自动执行）
```

- **日期口径一律北京时间（UTC+8）**；Pod 系统时间是 UTC，脚本已内置换算，无需自己加时区。
- 不传日期 = 今天；补记历史用 `YYYY-MM-DD` 格式。
- 脚本无 `--help` 等选项；参数写错会被当成内容记入，注意别误记。

### 怎么写才算好素材

- 一句话：**做了什么 → 结果 / 数据**（有数字写数字，有路径写路径）。
  - ✅ `压测台跑 8 并发，TTFT 从 120s 降到 35s（bench/run-20261013）`
  - ❌ `今天优化了一下性能`（无法追溯）
- 一次任务记一条；琐碎读取、临时试验不必记。
- 与代码相关的改动**正常 git commit 即可**，提交记录本身就是周报素材，不必重复 note。

## 3. 素材存储格式

文件：`~/docs/notes/notes.jsonl`（JSONL，每行一条，追加写入）：

```json
{"date":"2026-10-14","ts":"2026-10-14T20:23:23+08:00","source":"user|agent","text":"..."}
```

- `source`：`user` = 手动记录；`agent` = Claude 完成改动后自动记录（见 `~/.claude/CLAUDE.md` 常驻规则）。
- 该文件在 `~/docs`（持久化盘），Pod 重建不会丢失。
- 想删误记的条目：直接编辑该文件删除对应行即可。

## 4. 查看与汇总素材：`weeklog`

```bash
~/bin/weeklog                          # 默认本周（周一 ~ 今天，北京时间）
~/bin/weeklog 2026-10-05 2026-10-11   # 指定区间
```

输出两部分：
1. `/home/cloud` 下所有 git 仓库在区间内的提交（hash / 北京时间 / 作者 / subject）；
2. `notes.jsonl` 中区间内的用户与 agent 记录。

## 5. 生成周报：weekly-report skill

对 Claude 说 **「写周报」/「生成上周周报」/「汇总本周工作」** 即可，流程自动完成：

1. 按北京时间确定周报区间（默认本周；可指定「上周」或明确日期）；
2. 跑 `weeklog` 收集 git 提交 + note 记录；
3. 按模块（引擎 / RAG 网关 / 压测与评测 / 部署与运维 / 文档与协作）撰写中文周报；
4. 本地存档到 `~/docs/reports/周报-2026-Wnn.md`，并在对话里展示全文；
5. 发布到 iwiki「周报」空间（`space-1m3W4Cut`）；同周重复生成时更新既有文档而非重复发布。

纪律：周报只写素材里有依据的内容；素材少就写短周报，不灌水——所以**平时勤记 note，周报才写得好**。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 记错了日期 / 内容 | 编辑 `~/docs/notes/notes.jsonl` 删掉或改正对应行 |
| 误把命令参数记成了内容 | 同上，删除该行 |
| 忘了某几天做了什么 | 跑 `~/bin/weeklog 起 止` 看 git 提交，再补 note |
| 想让 agent 记改动 | 无需操作，Claude 按规则在每次有意义改动后自动 `note --agent` |
| 周报发布错了 | 在 iwiki「周报」空间找到该文档，用历史版本回滚或让 Claude `edit_doc` 修正 |
